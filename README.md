Describe your project in detail:
  - Explain the features and controls
The different repositories contain the ability to move through cube worlds.
It starts at Level 0, where you can move the cube around on the screen with your mouse.
 <img width="975" height="524" alt="image" src="https://github.com/user-attachments/assets/4f0503ea-93cb-4c0b-8648-9c8a5d8cab53" />

Level 1 includes the rendered cubes to view in different resolutions.
 <img width="975" height="745" alt="image" src="https://github.com/user-attachments/assets/556289dc-0d20-4837-8c9f-2c25d27b4c8e" />

Level 2 includes the ability to have a cube world from images. Different images can be uploaded to make sure different results follow.
 <img width="975" height="413" alt="image" src="https://github.com/user-attachments/assets/a7496c8c-2d63-4b46-aee0-d4bed6805149" />

Level 3 includes the ability to upload additional images.
This is to ensure different images can be combined to make a different fantasy/imaginary cube world. Resolution remains adjustable so that older hardware/software can be used.
 <img width="975" height="802" alt="image" src="https://github.com/user-attachments/assets/3e1d04d8-f2a3-40c6-9e95-f8968451e499" />


Level 4 includes lighting from a source off screen. The adjustments can be made via sliders. Additional objects to the cube world would assist in the view of the lighting.
 <img width="975" height="719" alt="image" src="https://github.com/user-attachments/assets/ad5233fd-a1f2-47bc-aab4-2e0606687f97" />

Fixed camera for the world to be viewed.
Bezier curve use for camera rotating around the worlds generated.
